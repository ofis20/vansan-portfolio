What you get

Ready for a production pipeline.

Maps are packed for the pipelines that actually get used, not dumped in a folder.

Eight maps, 2048²

Albedo, OpenGL normal, roughness, metalness, height, ambient occlusion, HDRP Mask Map and an ORM pack.

Unity, set up

Materials use Universal Render Pipeline/Lit, tested in Unity 6. A demo scene and an offline setup guide ship with the package.

Seamless, both axes

Every albedo is edge-matched and checked for horizontal and vertical tiling. No seam, no obvious repeat ghosting.

Engine-agnostic maps

The same PNG set works in Unreal Engine, Godot and Blender. OpenGL normals need the green channel flipped for DirectX.

Process

Generated, then finished by hand.

  1. GenerateAlbedo bases are produced locally with Stable Diffusion XL, under its commercial-use license.
  2. CurateEvery output is reviewed. Anatomical errors, broken reads and anything that resembles existing work are discarded.
  3. Make it tileSeams are repaired with inpainting and edge matching until the texture repeats on both axes.
  4. Derive the mapsHeight, normals, roughness, metalness and ambient occlusion are built procedurally from the finished albedo, then upscaled to 2K.

AI disclosure

Albedo base textures were generated locally using Stable Diffusion XL (commercial license) in ComfyUI. All generated outputs were curated, seam-repaired (inpainting and edge matching for seamless tiling), upscaled to 2048×2048, and processed with procedurally derived PBR maps (Height, Sobel Normals, Roughness, Metalness, and Ambient Occlusion). No third-party copyrighted materials were used as source inputs.
