Specification

Built for a production pipeline.

Every material carries the same map set, so a project can mix collections without rebuilding shaders.

  1. Eight maps at 2048 × 2048. Albedo, OpenGL normal, roughness, metalness, height, ambient occlusion, an HDRP mask map and a Godot ORM pack.
  2. Unity materials included. Each set ships as a Universal Render Pipeline/Lit material, tested in Unity 6, with a demo scene and an offline setup guide.
  3. Checked for tiling. Seams are repaired and every texture is verified on both the horizontal and the vertical axis.
  4. Not locked to one engine. The PNG maps import directly into Unreal Engine, Godot and Blender. DirectX workflows need the normal's green channel flipped.

Process

Generated first, finished by hand.

The albedo starts in a local Stable Diffusion XL workflow. Everything after that is selection and repair.

  1. Generate. Albedo candidates are produced locally, under the model's commercial-use license.
  2. Curate. Outputs with a broken read, or that resemble existing work, are thrown out.
  3. Repair. Seams are closed with inpainting and edge matching until the texture repeats cleanly.
  4. Derive. Height, normals, roughness, metalness and ambient occlusion are built procedurally from the finished albedo, then upscaled to 2K.
AI disclosure. Albedo base textures were generated locally using Stable Diffusion XL (commercial license) in ComfyUI. All generated outputs were curated, seam-repaired (inpainting and edge matching for seamless tiling), upscaled to 2048×2048, and processed with procedurally derived PBR maps (Height, Sobel Normals, Roughness, Metalness, and Ambient Occlusion). No third-party copyrighted materials were used as source inputs.
